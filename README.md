# Notion Pixel RPG Decor 🎮

讓 Notion 變成明亮可愛的像素 RPG 世界！

我想幫自己的 Notion 換上像遊戲一樣的封面和小圖示，
所以做了這個 skill，也分享給大家一起玩。

## ✨ 可以做什麼？

告訴 Codex 你喜歡的主題，讓它幫你製作風格一致的素材：

- 5 張 Notion 封面
- 10 個透明背景小圖示
- 圖示總覽和素材對照表
- 打包好的 ZIP 檔案

產生後，再把喜歡的封面和圖示自行上傳到 Notion。

## 💬 可以怎麼跟 Codex 說？

安裝這個 skill 後，可以試試：

「使用 notion-pixel-rpg-decor，幫我做一套森林冒險主題的
Notion 封面和圖示，用在任務看板、學習筆記與生活日誌。
希望配色明亮可愛，有小小冒險者和森林小屋。」

也可以換成你喜歡的主題！
